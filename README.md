
ГалаСпорт — Fitness Club Website
A modern, responsive website for ГалаСпорт, a fitness club based in Vsevolozhsk, Russia.
The project provides visitors with an interactive platform to explore the club’s services, discover membership plans, browse training programs, and submit booking requests.
🌐 Live Demo: https://ivar58.github.io/GalaSport/
✨ Features
	•	Responsive Design — Optimized for desktop, tablet, and mobile devices.
	•	Modern UI — Dark-themed interface with elegant layouts and smooth animations.
	•	Interactive Booking Modal — A booking form for visitors interested in the club’s services.
	•	Membership Calculator — Helps users discover suitable membership options based on their preferences.
	•	Fitness Programs — Information about fitness activities, swimming, personal training, and spa services.
	•	Pricing Sections — Displays membership plans and service prices.
	•	Training Schedule — Presents available group activities and training sessions.
	•	Reviews & FAQ — Dedicated sections for customer feedback and frequently asked questions.
	•	Contact Information — Club location, contact details, and opening hours.

🚀 Getting Started
Prerequisites
	•	Node.js 20 or later
	•	npm
Installation
Clone the repository:
git clone https://github.com/IVAR58/-SP.git
Navigate to the project directory:
cd -SP
Install dependencies:
npm install
Start the development server:
npm run dev
Production Build
npm run build
To preview the production build:
npm run preview
🌍 Deployment
The project is deployed using GitHub Pages.
A GitHub Actions workflow automatically builds the project and deploys the generated dist directory to the gh-pages branch when changes are pushed to main.
